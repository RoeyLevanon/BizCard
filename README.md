# BizCard – כרטיס ביקור דיגיטלי

שיעורי בית פרק 8 – Intents.

## מסכים
- **MainActivity** – טופס: שם, תפקיד, טלפון, אתר. כפתור "צור כרטיס" (עם בדיקת שדות ריקים) וכפתור "אודות".
- **CardActivity** – מציג את הכרטיס. כפתורים: חייג (ACTION_DIAL), פתח אתר (ACTION_VIEW), שתף (ACTION_SEND + createChooser), חזרה.
- **AboutActivity** – מידע על האפליקציה + חזרה.

## בונוס
- try/catch על ActivityNotFoundException עם Toast.
- מפתחות קבועים (KEY_NAME וכו') ב-MainActivity.
